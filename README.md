
# DSA Lab 7

**Course:** CS250 — Data Structures and Algorithms  
**University:** National University of Sciences and Technology (NUST)

## Task 1 — Binary Search

### Objective
Implement binary search to efficiently find a target element in a sorted array

### Concepts Covered
- Arrays
- Binary Search
- Divide and Conquer
- Time Complexity

### File Structure
- `task1_binary_search.cpp` — Implementation of binary search

### Time Complexity
- Best Case: O(1)
- Average Case: O(log n)
- Worst Case: O(log n)

### Space Complexity
- O(1) for the iterative implementation

### How to Compile and Run
```bash
g++ -std=c++17 -Wall -Wextra task1_binary_search.cpp -o binary_search
./binary_search
```
